    Overview

    This is a sample report demonstrating the webreport framework. The framework provides:

    • Dynamic table of contents (auto-generated from headings)
    • Responsive layout with fixed sidebar navigation
    • Pre-styled components for statistics, tables, galleries, and more
    • Image modal viewer with keyboard/click-outside support

    Usage Instructions

    1. Copy this template to your project location
    2. Adjust the CSS/JS paths based on your directory depth (e.g., ../css/webreport.css)
    3. Replace placeholder content with your data
    4. Use semantic h2/h3 headings for automatic TOC generation
    5. Add images to gallery with onclick="openImage('path/to/image')"
